# 六法全書

憲法・民法・刑法・商法・会社法・民事訴訟法・刑事訴訟法と行政法の条文を読んで検索でき、
重要条文をクイズで覚え、司法試験の短答式過去問を解けるアプリです。ブラウザだけで動きます。

条文は **e-Gov 法令API（デジタル庁）** の公式データから、
過去問は **法務省が公表した問題と正答のPDF** から、
判例は **裁判所ウェブサイトの裁判例検索** から作っています。

## 起動

`start.command`（Mac）または `start.bat`（Windows）をダブルクリックすると、
簡易サーバーが立ち上がってブラウザが開きます。

同じWi-Fiのスマホからは、起動時に表示される `http://192.168.x.x:8770/` で開けます。
ホーム画面に追加すればアプリとして使え、一度開いた法令はオフラインでも読めます。

サーバーを立てずに `index.html` を直接開いても動きます（条文は `<script>` で読み込むため）。
ただしオフライン対応（Service Worker）はサーバー経由のときだけ有効です。

## 画面

| タブ | できること |
| --- | --- |
| 📚 六法 | 法令を選び、目次から章・節をたどって条文を読む。目次のいちばん下が附則 |
| 🔍 検索 | 収録した全法令を横断して条文の本文・見出しを全文検索する。附則は「附則も含める」で入る |
| 🎓 重要条文 | 47の分野にまとめた415条を、ひとこと解説つきで読む |
| 📖 用語 | 善意・対抗・既判力など、法律用語55語の意味 |
| 📝 クイズ | 重要条文から5つの形式で自動出題する |
| ⚖️ 判例 | 重要判例54件を分野別に。判示事項・裁判要旨・参照法条は公式データ |
| 🏛 過去問 | 司法試験 短答式の過去問を、実際の配点どおりに採点しながら解く |
| 📊 記録 | 正答率・連続学習日数・苦手な問題・過去問の自己最高得点 |
| ⭐ 保存 | ブックマークした条文・判例、書いたメモ、保存した問題・過去問 |

ヘッダーの 🔖 は条文ジャンプです。`民法709` `憲法9` `刑法230の2` のように入れると
その条文に直接飛べます。番号だけなら、前に開いていた法令から探します。

附則は改正法ごとのかたまりで、制定時のものから順に並びます。本則と条番号がかぶるため、
附則の条には ⭐ とメモは付きません（保存先の鍵が衝突するのを避けるためです）。
日本国憲法に附則はありません（補則は第十一章として本則に入っています）。

学習記録・ブックマーク・メモは、その端末のブラウザ内（localStorage）にだけ保存されます。
サーバーには何も送られません。

## 行政法について

**「行政法」という名前の法律はありません。** 行政の手続と救済を定めた複数の法律の集まりです。
このアプリでは、その中核をなす5つを個別に収めています。

| 法令 | 略称 | 中身 |
|---|---|---|
| 行政手続法 | 行手 | 許認可や不利益処分をどう進めるか。行政指導と意見公募も |
| 行政不服審査法 | 行審 | 役所へ不服を申し立てる手続 |
| 行政事件訴訟法 | 行訴 | 行政の処分を裁判で争う手続 |
| 国家賠償法 | 国賠 | 公務員の違法行為や営造物の瑕疵による損害の賠償 |
| 行政代執行法 | 代執行 | 義務を果たさない者に代わって行政が実行する手続 |

条文ジャンプは `行政事件訴訟法9` でも `行訴9` でも飛べます。

## 過去問について

収録は **令和2年から令和7年までの6年分**、短答式の憲法・民法・刑法です（18セット・461問）。
いまの司法試験の短答式はこの3科目だけで、行政法は論文式（公法系科目）でしか出ません。
民法の債権法改正が施行された令和2年4月以降の年度に絞ってあります。
それ以前は改正前の条文を前提にした問題が混ざり、このアプリの条文と食い違うためです。

答える単位は実際の試験と同じ「解答欄」で、ひとつの問に1個または複数あります。
採点も実際の配点どおりで、「2問正解で部分点1点」のような部分点の規則にも従います。
出題の不備で受験者全員が正答として扱われた問は、そのように表示して満点を与えます。

途中でやめても解答は残り、次に開いたときに続きから再開できます。
通しで解き終えたときだけ、自己最高得点として記録されます。

⚙ 設定の「過去問をその場で採点する」を切ると、解答だけ進めて最後にまとめて採点できます。

## 判例について

司法試験の短答式で問われた条文を優先して、重要判例を54件収めています。
短答式の参照条文158件のうち86%が、判例の付いた条文です。

残る17件は、天皇（1条・3条・8条）、国会の議決手続（59〜61条）、内閣（65・66・70・72条）、
財政（88・90条）、地方特別法（95条）、憲法改正（96条）など、憲法の組織・手続規定です。
これらを解釈した最高裁判例は存在しないため、無理に結びつけていません。

**条文と双方向でつながっています。**

- 条文を開くと、その条文の判例がボタンで並びます（⚖️ この条文の判例）
- 判例の「参照法条」を押すと、その条文に飛びます

判示事項・裁判要旨・参照法条・事件番号・判例集の巻号頁は、
裁判所ウェブサイトの**公式データをそのまま**収めています。
事案の概要とひとことだけが、このアプリで独自に書いたものです。
各判例から、裁判所サイトの全文（PDF）にも飛べます。

## 条文を最新にする

法改正があったときは、ネットにつないだ状態で次を実行します。

```bash
python3 tools/build_laws.py --force
```

特定の法令だけなら `python3 tools/build_laws.py --force 民法 刑法` のように指定します。
`raw/` にあるデータから作り直すだけなら `--offline` を付けます。

収録する法令を増やすときは `tools/build_laws.py` の `LAWS` に
`(キー, 法令ID, 表示名, 略称, 色, アイコン, ひとこと)` を足してから実行してください。
法令IDは e-Gov で調べられます。

## 重要条文を足す・直す

`data-study.js` の `groups` に分野と条番号を書きます。条番号は条文データの `num` と同じ書き方で、
「第二百三十条の二」なら `230_2`、「第三十八条から第八十四条まで」なら `38:84` です。

書いたあとは

```bash
python3 tools/check_study.py
```

で、存在しない条番号を指していないか確かめられます。
`--all` を付けると、書いた条文の見出しを一覧で確認できます。

## 過去問を足す

新しい年度が公表されたら、`tools/build_exams.py` の `EXAMS` に
`(年度キー, 表示名, 西暦, 問題ページ, 短答式試験結果ページ)` を足して実行します。

```bash
python3 tools/build_exams.py            # 未取得の年度だけ
python3 tools/build_exams.py --force r8 # 指定した年度を取り直す
python3 tools/build_exams.py --offline  # raw/exams/ から作り直すだけ
```

ページのIDは法務省サイトで「令和◯年司法試験問題」「令和◯年司法試験短答式試験結果」を
探せば分かります。PDFのURLはページのHTMLから毎回拾うので、書き写す必要はありません。

変換のたびに、問題文から読んだ解答欄と正答表とを突き合わせます。
配点の合計が満点と合わない、解答欄が重複する・使われない、選択肢の番号が飛んでいる、
といった食い違いがあれば、その場で一覧に出して終了コードを1にします。
**食い違いが出たまま公開しないでください。**

## 判例を足す

`tools/cases_seed.py` の `CASES` に、裁判年月日と手書きの解説を書きます。
判決そのものは書きません。裁判所サイトから取ってくるからです。

```python
{'key': 'sonzoku-satsu', 'name': '尊属殺重罰規定違憲判決',
 'era': '昭和', 'y': 48, 'm': 4, 'd': 4,
 'expect': '尊属殺人',              # 検索結果の行に出てくるはずの語
 'jiken': '昭和45(あ)1310',         # 同じ日に複数あるときの絞り込み
 'cite': '刑集 第27巻3号265頁',      # 取り違え防止。巻号頁まで一致を確かめる
 'group': 'kenpo-byodo', 'exam': ['kenpo:14'],
 'facts': '…', 'point': '…'}
```

`expect` を空にしておくと、その日の裁判例を全部並べて報告します。
事件名や事件番号が分からないときは、まずそれで探してください。

```bash
python3 tools/build_cases.py              # 取得して cases/*.js を作る
python3 tools/build_cases.py 尊属殺        # 名前で絞って取る
python3 tools/check_cases.py              # 混入・実在チェックと、判例のない条文の洗い出し
python3 tools/rank_exam_articles.py --cases   # 出題が多いのに判例がない条文
```

**日付を覚え違えていたら、取得は必ず止まります。**
日付で検索し、`expect`・`jiken`・`cite` の三つで照合してから初めて採用する作りです。

## 出典

条文: [e-Gov 法令検索](https://laws.e-gov.go.jp/)（デジタル庁）の法令APIより取得。
判例: [裁判所 裁判例検索](https://www.courts.go.jp/app/hanrei_jp/)より取得。本則と附則の両方を収録しています。

過去問: [法務省ウェブサイト](https://www.moj.go.jp/jinji/shihoushiken/)で公表されている
司法試験の問題および正答・配点より取得。[公共データ利用規約（第1.0版）](https://www.moj.go.jp/hisho06_00280.html)に基づいて利用しています。
PDFから文字を起こして画面に組み直した部分はこのアプリによる加工で、法務省が作成したものではありません。

解説・分野分け・用語の説明・クイズは、このアプリで独自に用意したものです。
条文の正確さは e-Gov のデータに依存します。実務で使うときは原典をご確認ください。
